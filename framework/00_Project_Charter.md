# Automotive Consultation Framework (ACF)

## Vision

Define a structured, transparent and explainable methodology for automotive consultation.

## Mission

Create a vendor-neutral framework that can be implemented by software, consultants or AI systems.

## Objectives

- Improve customer decision quality.
- Standardize automotive consultations.
- Increase recommendation transparency.
- Provide measurable confidence.
- Create a repeatable consultation methodology.

## Success Criteria

A consultation performed using ACF should produce more consistent and explainable recommendations than an unstructured conversation.

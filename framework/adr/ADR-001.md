# ADR-001

## Title

The Framework Precedes the Software

## Status

Accepted

## Context

AutoMind originally started as an AI-powered automotive consultation application.

During product strategy discussions, we concluded that software should implement a well-defined methodology rather than invent one during development.

## Decision

The Automotive Consultation Framework (ACF) will be designed, researched and validated before major feature development continues.

AutoMind will become the first reference implementation of ACF.

## Consequences

- Framework decisions drive software architecture.
- Every feature must map to a section of ACF.
- Research precedes implementation.
- The framework remains technology-independent.

# ADR-001

## Title

ACF-Driven Development

## Status

Accepted

## Context

The Automotive Consulting Framework (ACF) and AutoMind are being developed together.

Designing the entire framework before software implementation may result in theoretical decisions that are not validated in practice.

Similarly, implementing software without a guiding framework may produce inconsistent consultation behaviour.

## Decision

AutoMind will be developed iteratively alongside ACF.

Each completed portion of ACF should be implemented within AutoMind.

Implementation feedback may improve future versions of ACF.

## Consequences

- ACF remains practical.
- AutoMind validates ACF.
- Framework and software evolve together.
